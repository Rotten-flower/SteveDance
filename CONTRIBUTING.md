# Contributing / 参与开发

Keep changes focused and describe their effect. Include Minecraft, Forge, Java and mod versions when reporting a bug. Attach the relevant log and reproduction steps.

修改应围绕具体功能。反馈问题时提供 Minecraft、Forge、Java 和模组版本，附相关日志与复现步骤。

Keep player-facing text in the language files and update both Simplified Chinese and English. Preserve stable registry IDs and player data. Do not commit credentials, local game directories, saves, logs or development screenshots.

玩家文字使用语言文件，同步简体中文和英文。保持注册标识与玩家数据稳定，不提交凭据、本机游戏目录、存档、日志或开发截图。

Document third-party code and material sources with their applicable terms. Project MIT licensing does not change third-party rights.

引入第三方代码或素材时记录来源与适用条款，项目 MIT 不改变第三方权利。
